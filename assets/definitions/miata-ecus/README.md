# miata-ecus definitions

Upstream: https://github.com/v3ai/miata-ecus

What: The `rusefi_miata-ecu.ini` artifact of a run of the repository's Firmware workflow (GitHub Actions artifacts expire: `python3 tools/gen_definitions.py --extract` recovers the committed copy).

Licence: GPL-3.0. The repository's own files are MIT, but this INI is generated by the rusEFI build the repository pulls in, so it is a rusEFI work under GPL-3.0.

Files are bundled unmodified; `sources.json` has the URL, commit, size and sha256 of each. Fetch them with `python3 tools/fetch_definitions.py --family miata-ecus`.
