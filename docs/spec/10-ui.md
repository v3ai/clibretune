# 10-ui: UI Specification (custom immediate-mode framebuffer GUI)

Source: libretune-app/src (React/TS, ~71k lines), src-tauri commands, docs/src. Priorities: P0 must, P1 should, P2 nice. OUT OF SCOPE: AI assistant/agent panels, MCP server, Lua console/ECU Lua editor, WASM plugins/PluginPanel, online INI search/update checks, git/version-control UI, i18n (English only), Tauri pop-out windows, firmware update (DFU/OpenBLT), onboarding/QuickStart marketing screens, Action recorder/scripting (P2 at best).

## 0. GUI toolkit requirements (C89, framebuffer)
- Immediate-mode core: `lt_ui_begin_frame(input)`, widgets return state (clicked/changed), `lt_ui_end_frame()` emits draw list (rect, line, text, clip, triangle-fill for 3D/gauges). Backend abstraction: present RGBA32 framebuffer + poll events (mouse xy/buttons/wheel, key down/up with modifiers, text input UTF-8/ASCII, resize). Backends: X11 (raw protocol over plat sockets), Win32 (GDI), Cocoa (Objective-C runtime from C), web, tty, plus a PPM/headless backend for tests (P0).
- Fonts: pixel backends render IBM Plex (Sans Regular/Medium/SemiBold, Mono Regular/Medium; subset, embedded as chunked arrays in `src/gui/fonts_data.c`, generated by `tools/gen_embed.py`) through our own TrueType rasterizer `src/gui/ttf.c` (exact-coverage AA, GPOS kerning, 1/4-px glyph positioning, x-height grid fitting, bounded glyph cache). API in gui.h: `lt_font_get(LT_FONT_SANS|..)`, `lt_gfx_text_ex` (y = top of line box) / `lt_gfx_text_bl` (y = baseline), `lt_gfx_text_measure`, `lt_gfx_text_fit`, `lt_font_ascent/descent/line_height`, `lt_gfx_text_rot` (gauge labels). Sizes follow the stock CSS scale (xs10 sm11 base12 md13 lg14 xl16 2xl18 3xl24); numbers use Plex Mono, headings SemiBold. The tty backend and the legacy `lt_gfx_text(..., scale)` keep the 8x16 cell font; in pixel mode that call is mapped onto Plex Mono 13.33px (exactly 8px advance, so layouts are unchanged; `g->bitmap_text = 1` restores the bitmap font). Box/block characters always use the bitmap font so they tile the cell grid. LCD font for gauges P2 (use mono).
- Icons: Lucide (24x24 grid, round caps/joins, stroke 2) converted by `tools/gen_icons.py` from `assets/icons/*.svg` into polylines (`src/gui/icons_data.c`, ids `LT_ICON_*` in icons.h, every icon imported by the stock app plus generic ones). `lt_gfx_icon(g, LT_ICON_FOLDER_OPEN, x, y, size_px, stroke_px, color)` draws them anti-aliased at any size/fractional position (stroke_px <= 0 = lucide default 2*size/24); `lt_icon_find("folder-open" | "FolderOpen")` looks ids up by name. Run `TESTS=test_ttf ./build.sh test` to regenerate the visual check `build/typography.ppm` (`python3 tools/ppm2png.py in.ppm out.png [zoom]`).
- Required widgets: label, button, toggle button (toolbar), checkbox, radio, combo/dropdown, single-line text/number input (with caret, selection, Enter/Esc), slider, scroll area (wheel+drag bar), tree view (expand/collapse), tab bar, menu bar + cascading popup menus + context menu, modal dialog stack, tooltip (hover 500ms), toast (auto-dismiss ~4s; kinds info/success/warning/error), progress bar, splitter (sidebar resize), color swatch/picker (RGB sliders P1), file-open/save dialog (own implementation: directory listing via opendir/readdir, filename field, filter; P0 since no native dialog), text area (read-only multi-line P0; editable P1).
- Canvas primitives needed: filled/stroked rect, line, polyline, arc/circle (gauges), filled polygon, clip rect, alpha blend. 3D table view: software rasterizer (orthographic/perspective, painter's-algorithm sorted quads with per-vertex heat color) P1.
- Redraw: event-driven, but 30-60 Hz when realtime data active (dashboard/table follow/autotune/logger). Input debounce none.

### 1.1 Toolkit text, icons and theme data (C port)
- Default UI text is Plex Sans 12px (`LT_UI_FS_BASE`); the sidebar tree, tabs and status bar use 11px (`LT_UI_FS_SM`), headings SemiBold 13-14px, buttons Medium 12px. `lt_ui_text_width`, `lt_ui_draw_text`, text fields (caret, selection, hit testing), wrapping and ellipsis all measure with the real font, so layouts are proportional in pixel mode; cell mode keeps 8x16. Explicit face/size: `lt_ui_draw_text_f`, `lt_ui_text_width_f`, `lt_ui_draw_text_in_f`; default style: `lt_ui_text_style` / `lt_ui_text_style_reset`.

- Stock theme tokens: `tools/gen_themes.py` converts the nine `[data-theme]` blocks of the stock `themes/variables.css` into `src/gui/ui_theme_data.c` (57 colors per theme); `lt_theme_preset` overlays a row on the built-in dark/light base. Extra metrics: `tree_row_h` 20, `radius_lg` 4, `title_h` 42 (dialog header), `tab_h` 28.
- Shell chrome (app_shell.c): menubar with divider zones (`lt_ui_menubar_separator`), icon toolbar (open, save, burn, connect, dashboard, AutoTune, log, settings), "PROJECT" sidebar header + search row (Ctrl+K, expand/collapse all) + icon tree (keyword -> Lucide icon rules mirroring the stock `nodeIcons.ts`, folder orange / table blue / dialog green), icon tabs with close buttons that shrink when crowded, status bar with connection dot / logging indicator, centred welcome screen with card-style recent projects, glass-card modals (`lt_ui_modal_begin`: dim overlay, soft shadow, elevated header with SemiBold title, close button), tabbed Settings dialog (`lt_ui_tabs_flat`).

## 3. Core workflows
1. First run -> Welcome -> "Connect ECU / New Project" -> Connect ECU Wizard -> project created+opened -> sidebar/menus populated from INI, Dashboard tab shown, tune loaded (or defaults offline).
2. Edit: open table/dialog from sidebar -> modify values (writes to local tune immediately via update commands; tune_modified=true; tab title/status shows modified) -> if Connected, each constant edit is also written to ECU RAM page (live) -> Burn (Ctrl+B) persists to ECU flash.
3. Save tune writes .msq (Save dialog: filename in project Tunes dir, overwrite confirm); Load tune (Open dialog lists project tunes + browse); mismatch dialogs (below).
4. Close project -> back to Welcome. On exit with unsaved tune: confirm Save/Discard/Cancel (P0).
### 3.1 Connect ECU Wizard (modal, P0)
Steps by transport. Transport choices: usb (serial), bluetooth (serial COM), tcp (host+port), offline. Offline steps: [transport, name]. Others: [transport, params, connect, resolveIni, name]. Header shows step i/n; Back/Next/Cancel; Finish on last.
- transport: radio list USB/Serial, Bluetooth, TCP/WiFi, Offline.
- params: serial: port dropdown (scan serial ports, Rescan button) + baud dropdown (9600, 38400, 57600, 115200, 230400, 460800, 921600; default 115200); tcp: host + port number.
- connect: automatically attempts connection once per (transport,port,baud,host) key, reads signature; shows spinner/status, error with Retry; on success disconnects probe link, keeps signature.
- resolveIni: auto-match signature against installed INIs (exact, then family match); list of candidates (id, name, signature) to pick; button "Browse for INI file..." (last resort import); can't proceed without INI.
- name: project name text field (validated: non-empty, no path separators; duplicate -> error). Offline: also INI chooser (list of available INIs + browse).
- After finish: create_project(name, ini, connection{port,baud,auto_connect}), open it.
Open Project: from Welcome recent list or File > Import. Import Project Wizard (TunerStudio dir): choose folder (file dialog), preview detected INI/MSQ/dashboards, confirm; creates project; migration report dialog (P2).
### 3.2 ECU Connection dialog (P0)
Fields: port dropdown+rescan, baud dropdown, auto-connect checkbox, Connect/Disconnect buttons, status text, protocol/timing options (P2). Signature mismatch dialog (P1): shows ECU sig vs INI sig; buttons: Use matching INI / Continue anyway / Cancel. Tune mismatch dialog (P1): ECU data vs project tune differ -> choose "Use ECU data", "Keep project tune", "Compare".
### 3.3 Burn dialog (P0)
Confirm modal: "Burn to ECU writes the current tune to permanent flash." Pin-conflict list if any (checkbox "acknowledge and burn anyway" -> force=true); buttons Burn/Cancel; busy state while burning; error line on failure; on success toast and clears tune_modified (onBurned). Burn only enabled when connected.
### 3.4 Restore points (P1)
Dialog listing restore points (name, date, size/note), buttons Create (auto-name by timestamp + optional note), Load/Restore (confirm), Delete (confirm), Close. File > Create Restore Point creates one silently with toast. Auto-created before burn/load (backend).
### 3.5 Save / Load tune dialogs (P0)
Save: filename field (default current), Save/Cancel. Load: list of tune files in project Tunes + "Browse..."; after load, if signature differs from INI show mismatch dialog.

## 4. Table editor (P0) -- most important screen
Opened from INI `table` targets. Data: x_bins, y_bins, z_values[rows][cols], titles, axis names/units, x/y output channels (for live cursor), precision/digits, scale/min/max for clamping, resizable info.
Layout: toolbar(top) / grid with X axis header row on top and Y axis column at left (Y orientation setting `table_y_axis_bottom`: row 0 at bottom when true; default true? -- stored boolean, toolbar toggle "Y axis zero at bottom") / optional 3D pane (toggle) / status line (selected cell value, axis values at cursor, live channel readouts).
Cells colored by heatmap of value (min..max over table) when Color Shading on (default on); text contrast chosen by luminance. Live cursor: cell containing current (x_channel,y_channel) outlined #00ff00 (bilinear weights highlight optional); trail of last N positions (fade seconds setting `table_trail_fade_sec`, trail color setting) P1. Follow mode (F): auto-select live cell (only available if x_output_channel).
Toolbar buttons (tooltips): Set Equal (=), Increase (+), Decrease (-), Multiply (*), Interpolate (/), Smooth (s), Re-bin, Set table size (resizable tables only), Generate (generate table from engine specs; P2), Copy, Paste, Undo, Redo, Follow Mode, Color Shading, Y-axis direction, Toggle 3D, Load/Save .table file (P1), Lambda/AFR preview (P2). Modified indicator and per-table "Burn"/send hint.
Selection: click select cell; Shift+click or drag = rectangle; Ctrl+click toggle; Shift+arrow extends; click axis header selects row/col (P1); Ctrl+A all. Editing: double-click or Enter or typing a digit starts inline edit (Enter commits, Esc cancels); axis bins also editable (re-bin dialog for bulk).
Keys (exact from source, table focused; Ctrl or Cmd):
- Arrows: move selection (Up/Down respect Y-orientation: with y_axis_bottom, Up = row+1). Shift+arrow extends.
- `=` set selected to average (rounded to precision). `>` `.` increase by delta (0.1 default, 1 with Shift) x multiplier (Ctrl=5). `<` `,` decrease likewise. `+` add 1*mult, `-` / `_` subtract 1*mult. `q` also increase in TableEditor2D. PageUp/PageDown +/-0.1; Shift = 1; Ctrl = 0.05. (Increments are in displayed units, and apply on the value scale then clamp to [min,max] of the constant.)
- `*` open Scale dialog (mul factor; also modes add/mul with error validation); `/` interpolate between selection corners (bilinear for 2D, linear along line if 1 row/col); `h`/`H` interpolate horizontally (each row between its end cells); `v` interpolate vertically (without Ctrl); `s`/`S` smooth; `f`/`F` follow mode; `g`/`G` jump to active (live) cell; Ctrl+C copy (tab-separated rows to clipboard; internal clipboard fallback); Ctrl+V paste at selection origin (clipped to table; if clipboard is 1 cell and selection larger, fill); Ctrl+Shift+V paste special (add/multiply) P2; Ctrl+Z undo; Ctrl+Y or Ctrl+Shift+Z redo; Delete clear (set to min) P2; Esc reset-to-original (revert unsaved edits to tune as loaded) / close menus; Enter edit; `3` toggle 3D.
Smoothing/interp exact algorithms: see 05-tables spec (table ops); UI calls lt_table_* ops and pushes undo snapshot before each op (undo stack unlimited P1, min 50).
Right-click context menu (P1): Set Equal, Increase/Decrease..., Scale..., Interpolate (both), Smooth, Fill (flood), Copy, Paste, Lock cells (locked cells shown with lock tint; skipped by autotune and bulk ops; per-session set).
Dialogs: Scale/Adjust dialog (value, mode), CellEdit dialog (numeric entry), Re-bin dialog (new X bins list, new Y bins list, "interpolate Z" checkbox), Set Table Size dialog (cols/rows within min/max from INI size constants), Table Compare dialog (two tables side by side/diff coloring richer blue/leaner red).
Writes: every edit -> `update_table_cell(s)` => lt_tune_set + mark modified + (connected) write to ECU page chunks. Multi-page tables handled by core.
### 3D view (P1)
Wireframe/surface mesh of z_values over x/y bins; heat-colored vertices; rotate (left-drag: yaw/pitch), pan (right/middle drag), zoom (wheel), reset view button; click a vertex selects cell (two-way sync with grid selection); live position marker (green sphere/cross); axes labels with units; Z scaled to [min,max]. Software rasterizer: transform, sort quads far-to-near, fill polygons with averaged cell color, draw edges.
## 5. Curve editor (P0, 1D)
Opened from INI `curve` targets. Data: x_bins, y_bins (editable), labels, x_axis/y_axis (min,max,step) for plot ranges, x_output_channel (live marker), optional gauge. Layout: plot (grid lines, polyline with draggable point handles) + editable list table (x,y columns) + toolbar. Interactions: drag point vertically (and horizontally if x editable, clamped between neighbors); click list cell to type value; arrows navigate; Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) undo/redo; Enter commit / Esc cancel in cell; context menu (P2). Live: vertical line/dot at current x channel value interpolated on curve. Edits write immediately like tables. Axis ranges fallback to data min/max with 5% padding.

## 6. INI-driven dialogs (DialogRenderer, P0)

## 12. Cross-cutting behavior
- Toasts for success/errors of all backend operations; error detail dialog ("Show details") P2.
- Long ops (connect, burn, sync, load INI) show modal busy dialog/progress; UI thread must not block: core runs serial I/O in non-blocking polling inside frame loop (single-threaded design) or a worker thread where available.
- Realtime store: map channel name -> latest value; widgets read by name; poll ~30-60 Hz when any subscriber visible; stop when disconnected.
- Units: unit conversion (temperature C/F/K, pressure kPa/psi/bar, speed, AFR/lambda) applied at display; stored values unconverted.
- Persisted UI state: theme, sidebar width/visibility, window size, last project, recent list, per-table prefs.
- Accessibility: keyboard focus order Tab/Shift+Tab, visible focus ring (border-focus #1a77d3).
- Window: min size ~1024x600; default 1280x800.
